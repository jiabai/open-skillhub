# Exec Plans

## Purpose

Exec plans capture task-specific implementation intent, progress, and recovery context. They are living documents while work is active and a historical record once completed.

## Entry Points

- Active plans: `active/index.md`
- Completed plans: `completed/index.md`
- Shared debt list: `tech-debt-tracker.md`

## Rules

- Keep active work in `active/`.
- Move completed work to `completed/` once the task outcome is landed or superseded.
- Capture cross-cutting debt in `tech-debt-tracker.md` instead of scattering TODOs across unrelated docs.
