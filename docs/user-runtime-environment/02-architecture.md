### 目录结构

```
{VENV_STORAGE_PATH}/                    # 虚拟环境存储根目录
├── {user_id_1}/                        # 用户 A 的虚拟环境
│   ├── bin/
│   │   ├── python                      # Python 解释器
│   │   └── pip                         # pip 工具
│   └── lib/
│       └── python3.x/
│           └── site-packages/          # 已安装的包
├── {user_id_2}/                        # 用户 B 的虚拟环境
│   └── ...
└── {user_id_3}/                        # 用户 C 的虚拟环境
    └── ...

{SKILL_STORAGE_PATH}/                   # Skill 文件存储根目录（现有）
├── {user_id_1}/
│   └── {skill_name}/
│       ├── SKILL.md
│       ├── _versions/
│       └── ...
└── ...

> **注**：Windows 系统下虚拟环境的 `bin/` 目录为 `Scripts/`，`lib/python3.x/` 目录结构相同。
```
