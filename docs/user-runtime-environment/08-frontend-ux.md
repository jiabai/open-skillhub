Skill 列表页中，每个 Skill 卡片显示状态标识圆点：

| 状态 | 圆点颜色 | 操作按钮 |
|------|---------|---------|

| ready | 🟢 绿色 | 「执行」 |
| failed | 🔴 红色 | 「重新部署」 |

### 2. 上传流程交互

上传流程大幅简化，不再需要等待安装完成。

### 6. 前端组件设计建议

#### 部署状态组件 (DeployStatusBadge)

```typescript
interface DeployStatusBadgeProps {
  installStatus: 'pending' | 'installing' | 'ready' | 'failed';
  installError?: string;
  onDeploy: () => void;
  onRetry?: () => void;
}
```

#### 依赖预览组件 (DependencyPreviewDialog)

```typescript
interface DependencyPreviewDialogProps {
  skillUuid: string;
  skillName: string;
  dependencies: {
    to_install: PackageInfo[];
    already_installed: PackageInfo[];
  };
  estimatedDurationSeconds: number;
  onConfirm: () => void;
  onCancel: () => void;
}
```

#### 冲突对话框组件 (ConflictDialog)

```typescript
interface ConflictDialogProps {
  skillUuid: string;
  conflicts: ConflictInfo[];
  affectedSkills?: AffectedSkillInfo[];
  onProceed: () => void;
  onCancel: () => void;
}
```

#### 安装进度组件 (InstallProgressDialog)

```typescript
interface InstallProgressDialogProps {
  skillUuid: string;
  progress: {
    current_package: string;
    current_version: string;
    completed_packages: string[];
    total_packages: number;
    progress_percent: number;
    elapsed_seconds: number;
    estimated_remaining_seconds: number;
  };
}
```

> **进度更新方式**：推荐轮询方案（内部用户场景），每 2-3 秒调用 `GET /api/v1/skills/{uuid}/deploy-status`。
