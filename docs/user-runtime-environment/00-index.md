# 用户级运行时环境设计文档

本文档描述了 Open SkillHub 的用户级运行时环境设计方案。由于 skill 的 scripts 脚本会在服务端运行，需要为每个用户的私有 skill 空间搭建独立的运行时环境。

## 快速导航

### 核心概念

- **隔离模型**：用户级别隔离，每个用户拥有独立的 Python 虚拟环境
- **安全隔离**：subprocess + 环境清理 + 脚本扫描
- **并发安全**：用户级操作锁，防止安装过程中执行

### 关键流程

1. [Skill 上传流程](./04-core-flows.md#1-skill-上传流程含环境创建和依赖安装) - 环境创建、依赖安装、冲突处理
2. [Skill 执行流程](./04-core-flows.md#2-skill-执行流程) - 权限验证、环境检查、脚本执行
3. [Skill 删除流程](./04-core-flows.md#3-skill-删除流程) - 文件删除、依赖保留策略
4. [版本回滚流程](./04-core-flows.md#6-skill-版本回滚流程) - 代码回滚、依赖保持

### 设计决策速查

| 决策项 | 选择 |
|--------|------|
| 隔离模型 | 用户级别隔离 |
| 安全隔离层级 | subprocess + 环境清理 + 脚本扫描 |
| 环境创建时机 | 首次上传 skill 时 |
| 依赖安装时机 | 用户确认后自动安装 |
| 依赖冲突策略 | 前端交互式处理 |
| 并发安全 | 用户级操作锁 |

详细决策理由请参考 [概述 - 核心决策](./01-overview.md#核心决策)。
